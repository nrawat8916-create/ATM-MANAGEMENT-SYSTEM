# ATM-MANAGEMENT-SYSTEM
A simple and user-friendly ATM Management System developed in C language. This project simulates basic banking operations such as balance inquiry, cash deposit, withdrawal, PIN change, mini statement.

Features:

Secure PIN Authentication

Balance Checking

Cash Deposit & Withdrawal

PIN Change Facility

Mini Statement (Last 5 Transactions)

5% Interest Calculation
