# ATM-MANAGEMENT-SYSTEM
A simple and user-friendly ATM Management System developed in C language. This project simulates basic banking operations such as balance inquiry, cash deposit, withdrawal, PIN change, mini statement generation, and interest calculation. he system also uses file handling to store user data permanently,.
